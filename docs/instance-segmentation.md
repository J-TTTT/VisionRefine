# 实例分割工作台

本阶段提供实例分割的数据结构与人工编辑。新建项目选择“实例分割”和“仅图片”，
填写本地图片目录与类别，导入后打开标注工作台。使用已有的项目目录、人工版本、
原图坐标和类别机制；原始图片不会被修改。

## 操作

- **＋ 多边形 / N**：逐点单击绘制。Enter 或点击起点闭合；Esc 取消，Backspace 删除草稿末点。
- **选择 / 顶点 / V**：单击内部选择实例；拖动顶点调整边缘；Shift+点击边插入顶点。
  选中顶点后用“删除顶点”或 Delete 删除，至少保留三个顶点。拖动多边形内部可整体移动。
- **追加轮廓**：给选中的多边形实例增加一个分离部分。各部分共享同一实例 ID 和类别。
  选择某个顶点后，“删除此轮廓”删除其所属部分；最后一段删除后，该实例也删除。
- **画笔 / B**：给选中实例增加像素。“＋ 画笔实例”创建另一个实例；标签使用当前候选标签。
- **橡皮擦 / E**：擦除选中实例的像素，可产生孔洞或分离部分；不会擦除其他重叠实例。
- **半径**：单位是原图像素，范围 1–256。缩放不会改变实际笔刷大小。
- **改类与删除**：点击画布上的标签选择类别；“删除实例”删除整个实例。
- **平滑、收缩、扩张**：先选中实例，再按原图像素设置调整半径并预览。平滑去除细小毛刺，
  收缩或扩张边界；默认保护原有孔洞，若操作会填平孔洞则提示缩小半径。
- **智能贴边**：在设定的最大移动距离内，结合图像颜色和 Canny 边缘优化当前边界。
  结果受图像对比度影响，应用前请检查绿色预览，必要时继续用画笔修正。
- **合并所选**：在选择模式按 Ctrl/⌘ 点击多个实例，再点击“合并所选”。不同类别合并时
  会要求确认，目标类别取当前候选标签。远距离区域保留为同一个实例的稀疏掩码。
- **拆分实例**：直接点击可按不相连区域拆分；若实例连在一起，可先用“画分割线”穿过连接处，
  再点击“拆分实例”。拆分保留原有前景像素，生成独立实例。
- **预览与应用**：上述操作先显示绿色结果和面积、孔洞及边缘指标。点击“应用预览”后才修改
  当前标注，并可撤销；“取消”不会修改标注。保存前须先应用或取消预览。
- **撤销 / 重做**：按钮或 Ctrl/⌘+Z、Ctrl/⌘+Shift+Z、Ctrl+Y。支持绘制、顶点、画笔、改类和删除。
  撤销历史在当前图像会话中保留，最多 25 步，并受内存预算限制；刷新后通过已保存版本恢复。
- **缩放和平移**：滚轮缩放，右键或空格拖动。坐标始终保存为原图坐标。
- **保存人工检查**：保存当前所有实例；没有实例时表示人工确认空标注。
  未闭合轮廓不能保存。切换图片时会提示尚未保存的修改。

多边形初次使用画笔/橡皮擦时会栅格化为二值掩码（覆盖率至少 50% 的像素置为前景），
之后用画笔精修。撤销可以恢复转换前的可编辑顶点。掩码不会被自动拟合为近似多边形。
当前多边形部分必须简单、互不相交且互不包含；孔洞通过掩码橡皮擦表达。
掩码选择按真实前景像素命中，因此点击孔洞或透明区域不会误选该实例。
边界调整后结果以像素掩码保存，多边形顶点不会继续作为矢量顶点编辑；可撤销恢复原多边形。
单次边界处理限制在约 419 万原图像素内，超过时可缩小实例或分区处理。

## 数据契约

`Annotation.kind` 支持 `bbox`、`polygon`、`mask`。检测使用 bbox；实例分割使用后两种。

- `polygon`：`polygons` 是多段轮廓，每段为 `[[x,y], ...]`，至少三个不同顶点，首点不重复闭合。
  每实例最多 256 段轮廓、2048 个顶点。面积为各独立轮廓的几何面积之和。
- `mask`：`mask.encoding = tile-rle-row-v1`，`tile_size = 128`，`tiles = [{x,y,counts}]`。
  `x/y` 是原图中 128 的整数倍。每块按行展开，counts 从背景段开始，0/1 交替，总长 16384。
  全背景块省略。不同实例独立存储，允许重叠；同实例多块可相距很远。
- `bbox` 与 `area` 由服务端重新计算；掩码面积为前景像素数，不信任客户端缓存值。
- 拒绝非有限值、自相交、退化轮廓、重复块、错误 RLE 和越界前景，失败时不写入人工版本。
- 掩码最多 4096 块、100 万个 RLE 段；超出编辑预算时保留原结果并提示。
  位图计算按块进行，不分配整张原图大小的实例掩码。多边形转画笔按每段轮廓范围处理，
  超过容量的对象可以继续用顶点精修。

实例分割的数据集 schema 为 `3.0`，人工标注文档标记 `annotation_schema_version: 2.0`。
旧的检测数据集 1.0/2.0 与检测标注继续可读。
`annotations/` 保存最新人工版本，`revisions/<revision>/previous.json` 保存前一个版本，
`parent_revision_id` 记录关联。已有的 AI 建议优先级与人工空标注语义同样适用。

## COCO 实例分割导入与导出

创建项目或追加数据时选择 **COCO Instance Segmentation**，图片根目录对应 JSON 的
`file_name`；选择含 `images`、`categories`、`annotations` 的实例分割 JSON。
支持多边形、压缩 RLE 和未压缩 RLE。普通多段多边形保留可编辑顶点；重叠、复杂或越界
多边形会合并并栅格化为掩码，同时在导入报告中提示。缺失或损坏的分割几何会记录错误，
不会偷偷退化成检测框。导入的空标注图片也会保留。

保存人工标注后，在“数据集导入 / 导出”选择 **COCO Instance Segmentation**，先检查
导出兼容性，再提交后台任务并下载 ZIP。`annotations.json` 包含所选的全部划分，
`annotations/instances_<split>.json` 供按划分使用；可以选择是否附带图片。
像素掩码转换为 COCO 列优先压缩 RLE，孔洞和同一实例的分离区域按像素保留。
类别名称、`iscrowd`、原图尺寸和人工确认的空图片也保留；来源 ID 会重新生成，
置信度与审核修订信息留在 `visionrefine.json`。单张图像超过 COCO RLE 的
2³²−1 像素限制时，导出预检会阻止该掩码。

内部块 RLE 使用行优先，不能直接作为 COCO 的列优先 RLE 使用；格式适配器负责转换。
YOLO 实例分割导出和分割模型接入仍属于后续阶段。
智能贴边在服务端运行，需要安装 `pip install -e '.[segmentation]'` 以提供 NumPy 和 OpenCV。
