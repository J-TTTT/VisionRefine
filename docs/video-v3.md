# 第三版：默认模型与自定义模型服务

## 目标与页面

第三版在第二版的视频事件、描述、抽帧和实例轨迹之上，加入可审核的 AI 建议。

- 图片／视频工作台的 **AI 辅助标注**：选择能力、模型、输入范围，查看任务和建议。
- **/ai**：共享模型设置、默认能力分配、连接测试。
- 图片现有切片检测继续使用旧适配器；新的默认整图接口支持最多 1600 万像素。超大图的浏览和人工编辑仍使用原有实现。

| 能力 | 默认模型 | 输入／输出 |
| --- | --- | --- |
| 图片检测 | google/owlv2-base-patch16-ensemble | 项目类别 → 原图像素框；英语类别通常更适合此模型 |
| 图片交互分割 | facebook/sam2.1-hiera-tiny | 前景／背景点、框、已有轮廓 → 可编辑掩码 |
| 视频实例分割传播 | 同上 | 已保存的对象关键帧、指定区间 → 同一对象逐帧可见掩码 |
| 视频描述 | Qwen/Qwen3-VL-2B-Instruct | 采样画面 → 整段／片段描述 |
| 视频事件 | 同上 | 采样画面、固定事件标签及补充要求 → 时间区间／时间点建议，也支持自由描述 |

视频理解目前只使用画面。采样可能遗漏快速事件，时间边界需要逐帧复核。SAM 2 的遮挡预测也需要人工检查；不能把有掩码等同于物体确实可见。

## 标注流程

### 描述与事件

1. 保存当前标注，打开 AI 面板，选择视频描述或事件。
2. 设置起止帧和采样数量（默认 12，最多 32）；整段默认覆盖全部视频。
3. 选择全局默认模型，或为该项目选择已配置的自定义服务。
4. 生成任务。可以关闭面板，稍后从这个素材的任务列表继续查看。
5. 勾选需要的建议，采纳到草稿；其余建议可以拒绝。
6. 在原工作台调整文字、时间或类别，人工确认审核。

已有事件和描述始终保留。AI 只追加所选建议，不直接替换人工内容。类别必须引用项目中真实存在的标签 ID，模型不能凭空建立对象关联。

### 视频分割与修正后传播

1. 创建对象，设置类别和生命周期，画出至少一个可见关键帧，保存。
2. 在分割选项卡打开 AI 面板，选择对象、区间和起始关键帧。
3. 模型使用区间内的人工关键帧及所选起始帧进行传播；结果仍属于原对象 ID。
4. 在建议列表按帧筛选，预览轮廓，采纳部分或全部待审核帧。
5. 在工作台检查轮廓。局部遮挡只保留可见像素；完全遮挡或离开时明确记录状态。
6. 修正并保存轮廓后，可以对同一区间再次传播。人工修正、人工绘制、已审核帧、明确的遮挡／离开区间都受到保护。未审核的旧 AI 帧可以由新的建议更新。

建议中的空掩码暂记为待审核的“完全遮挡”，需要人工判断是否其实离开画面。已明确标记为完全遮挡或离开的帧，不采纳传播轮廓。单任务最多 1000 连续帧，不使用固定 FPS 推算时间。

### 图片交互分割

1. 在实例分割图片项目中打开图片，保存已有编辑。
2. 打开 AI 面板，选择类别，在画面上点击前景／背景或拖框；也可使用工作台中选中的轮廓。
3. 预览并采纳建议，返回画布精修。
4. 点击“保存人工检查”才成为人工确认结果。

采纳产生独立的 ai_drafts 文件，原人工版本仍保留。仅导出已审核数据时使用人工版本；包含 AI 的导出可以包含已采纳草稿。新的人工保存会使旧 AI 草稿失效。

## 数据与兼容

- 全局配置：workspace/ai/config.json；项目能力选择：项目目录下 ai/bindings.json。
- 任务：项目目录下 ai/jobs/<job-id>/job.json；输入快照保存在同目录 input.json。
- 输入记录模型配置、来源指纹、标注版本、区间与关键帧。结果记录来源模型、权重版本（服务提供时）、任务 ID、生成时间和输入版本。
- 任务状态：queued → running → completed／failed／cancelled。应用重启后遗留任务标为 interrupted，可以基于当前数据重试。
- 多个能力共用两条应用后台线程；默认模型服务使用一条 GPU 队列，切换模型时释放上一模型。
- 采纳前校验来源与标注版本。任务运行期间发生编辑时，旧建议不能覆盖新修改。
- 建议逐条记录 pending／accepted／rejected。拒绝不修改标注。
- 带 AI 来源信息的视频导出使用 visionrefine-video 3.0；继续导入 1.0／2.0，重新导入统一清除审核状态。
- 模型服务故障时明确报错，不自动切换到其他服务或把数据发往其他地址。
- 模型权重、项目数据、服务密钥都不进入 Git。密钥只配置环境变量名称。

## 本版边界

- 未实现音频转写、听觉事件识别、自动审核通过、跨视频身份识别或模型训练。
- 自定义接口负责部署与推理；服务端仍执行类别、坐标、时序、大小及版本校验。
- 当前应用和默认模型 worker 均按单进程启动。多个应用进程不能共享这套进程内任务锁。
- 默认模型按需加载，首次使用较慢。没有模型服务时仍可正常进行人工标注。
- OpenAI 兼容服务没有统一取消接口；取消后结果不提交，但远端可能继续运行到完成或超时。
- 采纳和拒绝记录保留在项目任务历史中。已有的标注修订历史可用于追溯；本版未新增跨文档“一键撤销全部 AI”按钮。
