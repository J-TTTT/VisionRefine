# 视频标注第二版：人工实例分割

## 标注规则

第二版在视频事件、描述和抽帧工作台中增加实例分割。面向几秒到 30 秒的短视频，使用稳定的对象 ID 连接同一对象在不同帧中的标注。

用户确认的遮挡规则是：**只标实际可见部分**。部分遮挡时，一个对象可以有多块可见轮廓；完全遮挡时记录“完全遮挡”，不绘制推测轮廓。对象重新出现后，继续使用原对象 ID。离开画面可以记录“画外”。

| 概念 | 含义 |
|---|---|
| 对象类别 | 项目内共享的类别，可新增、改名或从 TXT / JSON 导入；与事件标签分别管理 |
| 对象 ID | 视频内同一实体的身份；类别相同的两个对象仍有不同 ID |
| 对象起止帧 | 此轨迹需要检查的帧范围，包含起止两帧 |
| 可见关键帧 | 保存该帧实际可见的多边形或像素掩码 |
| 遮挡／画外区间 | 明确记录没有可见轮廓的帧，可一次设置连续区间 |
| 未标注帧 | 在对象起止范围内，尚无轮廓或状态记录的帧 |

界面帧号从 1 开始，保存及 API 使用从 0 开始的帧序号。定位仍使用源视频实际时间戳，适用于可变帧率视频。

## 工作流程

1. 打开视频，切换到“实例分割”，管理对象类别并新增对象。
2. 暂停到需要标注的帧，在原始分辨率画面上画轮廓。播放预览的缩放不改变保存坐标。
3. 用多边形标注清晰轮廓，用画笔补充可见像素，用橡皮擦去除背景或形成孔洞。可撤销、重做及调整边界。
4. 保存当前帧轮廓后，继续到下一帧；遮挡和画外状态可按区间记录。
5. 对照画面审核关键帧或状态，再审核对象／已检查区间。仍有未标注帧时，不能确认该对象或区间已完成。
6. 如需更正身份，可在指定帧拆分对象，或合并属于同一实体的轨迹。事件关联随操作更新。
7. 保存后导出原生 JSON；也可将选定帧连同已有轮廓提取到图片实例分割项目。

第二版不自动补齐两个关键帧之间的轮廓。缺少标注的帧会保持未标注；完整逐帧标注目前需要人工完成。AI 传播及人工修正传播结果属于后续版本。

### 对象与事件

一个事件可以不关联对象，也可以关联一个或多个对象。事件的固定标签和自由描述继续独立使用。删除仍被事件引用的对象前，需要先移除事件关联。

拆分会创建新的对象 ID，并按拆分时间调整事件关联。合并保留选中对象的 ID；如果两个轨迹在同一帧已有冲突记录，需要先处理冲突。删除区间标注会留下待补充的帧，不会把该区间视为已完成。

### 保存与审核

事件／描述与分割使用各自的版本号。保存时检查版本，防止另一窗口的旧内容覆盖新内容。对象拆分或合并涉及事件关联时，两个文档一起提交。

已画轮廓、已保存和已审核是不同状态。对象审核要求起止范围内每一帧都有经审核的轮廓或明确状态；区间审核也检查其中所有对象的覆盖情况。修改轮廓或身份后，需要重新审核。

## 数据与交换

- 分割保存原始显示画面的像素坐标；多段多边形用于不相连的可见区域，带孔洞或经过画笔修改的形状使用稀疏分块掩码。
- 掩码按内容压缩保存，历史版本引用相同的掩码资源。保存历史不会因后续修改而改变。
- 原生视频 JSON 第二版包含对象类别、对象 ID、关键帧、可见状态及事件关联；继续支持第一版事件／描述文件。
- 回导按源视频指纹匹配，并重置审核状态，保留待本地检查的草稿。
- “仅已审核”导出保留明确确认的内容，未覆盖帧不会被补成标注。
- 携带轮廓抽帧使用提交任务时的分割快照。图片中保留来源视频、帧和对象身份信息，导入为待审核标注。
- 派生图片项目可以继续使用现有图片实例分割编辑与 COCO 导出。图片中的后续修改独立保存。
- 同一派生项目中重复抽取已有帧会跳过该帧，保留已有图片标注；不会用视频轮廓覆盖图片中的人工修改。
- 当前视频交换格式为原生 JSON。视频专用训练格式适配和模型传播需要后续扩展。

## 手工验收

建议选择一段含移动、遮挡和重新出现的真实视频，先用较短区间测试。

| 操作 | 预期 |
|---|---|
| 暂停、拖动进度条、连续逐帧 | 精确画面、帧号和轮廓一致 |
| 新增两个同类别对象 | ID 不同，选择与编辑互不影响 |
| 为一个对象画两块可见区域 | 保存为同一对象的多段轮廓 |
| 画笔补边、橡皮擦孔洞、撤销重做 | 像素结果可恢复，刷新后孔洞保留 |
| 跳过几帧再画一个关键帧 | 中间帧保持未标注，不能直接确认完成 |
| 记录完全遮挡区间后继续画同一对象 | 遮挡期无几何，重新出现后 ID 不变 |
| 将事件关联到对象，然后拆分／合并 | 事件引用有效，受影响内容需要重新审核 |
| 保存、刷新、两个窗口分别编辑 | 数据恢复，旧版本保存产生冲突提示 |
| 导出并回导原生 JSON | 对象及孔洞保留，审核状态重置 |
| 携带轮廓抽帧并进入图片工作台 | 轮廓与来源对应，图片标注需要重新确认 |

启动、素材生成和第一版验收步骤见 [视频第一版设计与验收](video-v1.md)。

### 遮挡演示

运行 `.venv/bin/python -m scripts.create_video_segmentation_demo`，会生成一段 4 秒的合成视频并创建独立体验项目。橙色矩形经过固定遮挡物后重新出现，示例保留同一个对象 ID，预置 8 个可见帧和一段完全遮挡状态，全部为待审核草稿。脚本输出打开项目的网页路径；每次运行创建新项目，不修改现有项目。
